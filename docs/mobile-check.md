# 手機排版檢查 — 2026-10-31

## 範圍與結果

使用本機網站及瀏覽器 viewport 模擬 390×844、320×740。這不是實體手機驗收，也不是 Jasmin 新版首頁 PR #7 的驗收。

- 390px：場次列表、待辦頁、已預約場次截圖檢查。
- 320px：登入、註冊、忘記密碼、場次列表、已預約場次、待辦頁、雲端預約表單確認整頁 scrollWidth 等於 viewport 寬度。
- 待辦資料載入後確認版面；全選四件時浮動操作列在 320px 畫面範圍內（高度 118px）。取消選取，沒有批次完成或改動資料。
- 預約表單開啟待辦編輯，確認日期、備註及儲存／取消按鈕在窄螢幕內；取消編輯，未儲存。
- 已預約場次開啟「安排本場待辦」，沒有儲存變更。
- 等候區僅驗證尚未開放提示，在 320px 無橫向溢出。沒有改場次時間或進行視訊連線。
- 首頁僅查看目前本機版的手機呈現，未改首頁內容，避免與 Jasmin 的新版首頁重疊。

## 修正

- TaskBoard：手機導覽移到 Logo 下方，連結不拆字，較窄時可橫向捲動導覽，不再壓縮 Logo。
- Logo：文字不換行，圖示與整組 Logo 不被壓縮。
- 場次列表：名額與預約按鈕可換行。
- BookedTaskContent：編輯儲存／取消可換行並有至少 44px 高度。

## 尚待正式網址與實體手機驗證

- iPhone Safari／Android Chrome：鍵盤彈出、日期選擇器、輸入時自動放大、觸控拖曳排序。
- 活動開放時的等候區完整內容、相機預覽、多人房間控制、音訊權限與橫豎切換。本次只有閱讀房間響應式樣式，不能當作驗收通過。
- 長暱稱、超長無空格待辦與多名視訊參與者。
- 預約成功、實際寫入資料與手機行事曆匯入需另以測試帳號確認。
- 新版首頁 PR #7 合併後重測共用 Logo 與導覽。
