# 雜事房 Key Vision 指南

方向：溫暖、俐落的共同工作室｜版本 01｜2026-11-15

## 核心感受
安心坐下，和幾個人一起開始，各自完成眼前的一件事。溫暖、俐落、有陪伴感；操作頁保持清楚、安靜、可重複使用。不使用虛構人數、見證或成果數字。

## 色彩
| Token | 色碼 | 用途 |
| --- | --- | --- |
| Paper | #FFFDF8 | 主要頁面與卡片 |
| Cream | #FAF7F2 | 次要區塊與輸入欄 |
| Ink | #1C1917 | 標題、內文、深色空間 |
| Coral | #FF5A36 | 主要 CTA、焦點與少量重點 |
| Forest | #4A7260 | 成功、在線、專注與次要操作 |
| Border | #DDD6CB | 分隔線與邊界 |

亮橘不改成暗陶土色，也不做大面積背景。不混入淺藍、亮黃等大面積裝飾色。使用現有 Tailwind token，不另寫近似色碼。

## 字體與元件
- Logo 使用 Noto Serif TC；其餘標題、按鈕、內文與操作介面使用 Noto Sans TC。
- 不使用負字距；操作頁不使用超大型展示字。
- 一般按鈕、輸入框、卡片與選單使用 8px 圓角。膠囊僅用於狀態、標籤、分段控制與進度步驟。
- 主要按鈕：Coral 背景、Ink 文字。次要按鈕：透明或 Paper 背景、深色邊框與 Ink 文字。
- 卡片細邊框，輸入欄 Cream 底；避免堆疊裝飾卡片。陰影只用於浮層、帳號選單及需要層級的主要面板。
- 同一頁面保留一個最明顯的主要操作；鍵盤 focus-visible 必須清楚。

## 頁面節奏
Landing Page：品牌與主要 CTA → 三個簡短理由 → 近期場次 → 可驗證規則與授權回饋 → FAQ 與最後 CTA。
產品內頁：導覽 → 頁面標題 → 主要工作區，使用同一套色彩、黑體與圓角。
專注房間可使用深色，但沿用同一套品牌色、字體及控制規則。

## 不採用
全部標題宋體、全面陶土色、全部膠囊按鈕、漸層、光暈、條紋、裝飾球、無功能插畫、虛構數字、客戶 Logo 或未授權見證。

## 驗收與維護
390、768、1024、1440px 不溢出或遮擋；主要操作有一致可見的 focus-visible；動畫尊重 prefers-reduced-motion。更新規範須記錄日期、修改人與原因。
