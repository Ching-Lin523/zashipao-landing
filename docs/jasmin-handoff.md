## 行事曆與 LINE 進度

「加入行事曆」已完成，使用者已確認實際加入成功（未指定測試的行事曆種類）。正式部署後仍需驗證等候區連結。LINE 提醒尚未實作，不要宣稱已有 LINE 通知或行事曆自動同步。

### 第一階段：加入行事曆

- 已在「預約成功」及「已預約場次」尚未開始的場次提供按鈕。
- 本機匯出不附 localhost 連結；部署後使用 NEXT_PUBLIC_SITE_URL，未設定時使用當前 HTTPS 網址。
- TypeScript 與三項行事曆測試通過，涵蓋時區、中文格式與網址。
- 提供 Google Calendar 連結，以及 Apple／Outlook 可匯入的 .ics 檔案。
- 行程包含場次名稱、正確時區的起迄時間、正式網站等候區連結；不加入私人待辦內容。
- 使用者需自行確認儲存。第一版不自動同步：取消預約或場次改期後，需要自行更新行事曆。
- 提醒是否跳通知取決於行事曆與裝置設定，不保證通知送達。
- Jasmin 配合：確認可用的正式網址、按鈕位置與提示文字；不要把開發用的 127.0.0.1 網址放到對外行程。
- 驗收：手機與電腦都能加入、時間與時區正確、連結可進入正確等候區（未登入先登入），重複點擊及取消後的提示清楚。

### 第二階段：LINE 提醒

- 需要 LINE 官方帳號與 Messaging API。舊 LINE Notify 已停止服務。
- 使用者需加好友並安全綁定雜事房帳號，確認哪個 LINE 帳號對應哪位使用者。
- 後端需要定時檢查、發送、避免重複提醒、失敗重試，以及取消預約後停止提醒。
- 可先規劃開場前 5 分鐘提醒，附正式等候區連結；提供停止提醒／解除綁定方式。
- Jasmin 配合：確認官方帳號管理者、訊息方案／額度與提醒文案。這是後續規劃，不是目前已有功能。
- 單純加好友不代表已完成網站帳號綁定；Google 登入也不代表已取得行事曆寫入授權。
