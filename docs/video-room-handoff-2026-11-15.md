# 視訊房間更新交接｜2026-11-15

這批供 Jasmin 審查及測試，尚未完成正式站驗收，請先不要合併上線。

## 這次修改

- 桌面房間採左側視訊、右側待辦／聊天切換；聊天輸入區固定底部。窄螢幕上下排列，單人視訊使用單欄。
- 加入同場文字聊天、暱稱、未讀數；麥克風關閉時仍能聊天。訊息不保存，也不補發離線期間的訊息。
- 等候區預設啟動本機鏡頭預覽，仍需瀏覽器攝影機授權。可關閉鏡頭、選擇背景模糊。
- 進房自動沿用五分鐘內的等候區選項，麥克風保持靜音。直接開房間網址、重新整理且沒有有效設定時，需回到等候區準備。
- 背景模糊使用新增的 @livekit/track-processors 套件；模糊模型載入及裝置相容性需實測。
- 只保留「離開」及確認視窗：停止連線並返回預約，進度保留，未結束場次可再次加入。
- 移除新版介面的「提前結束」操作；舊的後端結束 API 與歷史 finished_at 資料仍保留，舊版已提前結束的參與不會自動重新開放。
- 隱藏房間重複的夥伴名單，仍保留在線心跳。增加自願分享目標提示，不自動公開私人待辦。
- 開場後預約按鈕顯示「進入房間」，鏡頭準備頁顯示「進房前準備」。
- /sessions/room/demo 為模擬 UI，可測試本機聊天操作，不連接真實視訊。

## 部署與資料

執行 npm install 安裝新增套件。沒有新增資料庫 migration 或環境變數。
LiveKit token 的 canPublishData 已開啟以支援聊天；仍需通過原有預約、場次時間與帳號驗證。
請勿將 .env.local 或金鑰放進 PR。
